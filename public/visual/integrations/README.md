# DFBK.app — Integrations visual assets

Dedicated asset folder for the animated `/integrations` page.

Planned files:

- `friseur-before.webp` — original salon photo before haircut
- `friseur-after.webp` — salon photo after haircut
- `friseur-optimized.webp` — DFBK-optimized final photo
- `smartphone.webp` — smartphone/hand visual used in the capture animation
- `dfbk-mark.svg` — page-local copy/reference of the square DFBK mark if needed

Rules:

- WebP for photographic assets
- SVG for logos/icons whenever possible
- keep animation assets isolated from `profession-cards`
- optimize for page weight before production use
- do not reuse generic profession-card images as animation source assets
