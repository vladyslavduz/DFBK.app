# DFBK.app Design System

Status: approved baseline design.

## Brand

DFBK = **Dein Foto bringt Kunden.**

Approved logo implementation:
- horizontal `DFBK.app`
- transparent background
- dark navy `DFBK`
- digital blue `app`
- amber dot reduced relative to the original concept
- thin white outline around the lettering for contrast
- thin graphite rectangular frame with slightly rounded corners
- automotive badge-like visual character

Primary web logo: `/public/brand/dfbk-logo.svg`
Compact mark / favicon: `/public/brand/dfbk-mark.svg`

## Approved colors

| Token | Hex | Usage |
|---|---|---|
| Brand navy | `#102A43` | headings, strong brand elements |
| Digital blue | `#2563EB` | primary buttons, links, active elements |
| Amber accent | `#FFB000` | highlights, small accents, logo dot |
| Main background | `#F7F8F5` | page background |
| Cards | `#FFFFFF` | cards, forms, panels |
| Main text | `#17212B` | body text, graphite frame |
| Secondary text | `#64748B` | helper text, descriptions |
| Borders | `#DDE3E8` | dividers, inputs, cards |
| Success | `#16834A` | success status |
| Error | `#B42318` | error status |

The color tokens are implemented as CSS variables in `src/styles/global.css`.

## Design direction

Simple, trustworthy, practical and modern. The layout keeps the public landing-page orientation inspired by established AI SaaS sites for trades, while all branding, text, code and product logic remain DFBK.app-specific.
