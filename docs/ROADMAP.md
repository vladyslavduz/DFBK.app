# DFBK roadmap

## Phase 0 — now
- Site shell and routes.
- Cloudflare/GitHub deployment.
- Legal placeholders.
- API connection points without secrets.

## Phase 1 — commercial MVP
- Basic account/auth.
- Business profile.
- Photo upload.
- AI photo analysis.
- German content generation.
- Result/review screen.
- Project archive.

## Phase 2 — distribution
- Google Business Profile.
- Instagram/Facebook.
- Telegram where useful.
- Scheduling/publication status.
- E-mail confirmation and password reset.

## Phase 3 — only after demand is proven
- Billing/subscriptions.
- Website/blog publishing.
- Client portal.
- Voice workflow.
- Team roles/approval workflow.
- Analytics and deeper automation.
