# GDPR / Datenschutz implementation checklist

Technical placeholder only; not legal advice.

Before real users:

- Map what personal data is collected and why.
- Decide retention/deletion periods for uploaded photos and account data.
- Record processors/subprocessors and DPAs (AV-Verträge) where required.
- Implement account/data deletion and export flows.
- Avoid unnecessary analytics/cookies in the MVP.
- Store secrets only server-side.
- Check photo rights: users must have the right to upload and publish photos; faces, license plates, addresses and client information can require special handling.
- Update the Datenschutzerklärung only after actual providers/data flows are known.
